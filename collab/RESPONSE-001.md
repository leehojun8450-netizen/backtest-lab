## ① Walk-Forward Analysis

**검토자 판정**: 사실 — 경로 의존 전략에 적용 가능하나 경계 처리 규칙 정의 필요
**구현 난이도**: 브라우저 JS 가능, O(W×N) · **권고**: 넣어야 한다 (Rolling, W ≤ 5)

| 지적 | 내용 | 프로젝트 판정 |
|---|---|---|
| Anchored vs Rolling | 사이클 상태(분할 소진·평균단가)가 유지되는 경로 의존 전략엔, 과거 장기 레짐을 축적하는 Anchored보다 **국면 변화 적응력을 검증하는 Rolling**이 적합 | **수용** — 기본값 Rolling. Anchored는 옵션으로 유지 |
| IS:OS 비율 | 표준 관행 **70:30** 또는 80:20 (Pardo 2008, Ch.7) | **수용** — 70:30. 기존 등분할 방식 폐기 |
| 스텝 수 | W ≤ 5 | **수용** — 상한 5 하드코딩 |
| 경계 사이클 | 미완료 사이클 강제 종료는 인위적 왜곡. **Clean Slate**(OOS 시작 시 현금 100% 재설정)로 데이터 누수 차단, 또는 **Event-driven Boundary Shift**(사이클 종결까지 OOS 시작 유예) | **이미 그렇게 구현돼 있었음** — 표준임을 확인받은 것. Boundary Shift는 채택 안 함(구간 길이가 종목마다 달라져 비교가 흐려진다) |

**출처**
- Robert Pardo (2008), *The Evaluation and Optimization of Trading Strategies*, Wiley
- QuantStrat Walk-Forward Best Practices Document

## ② Deflated Sharpe Ratio (DSR)

**검토자 판정**: 사실 · **난이도**: 브라우저 JS 매우 용이, O(1) · **권고**: 강력 권고(최우선)

**출처**: Bailey & López de Prado (2014), *The Deflated Sharpe Ratio: Correcting for Selection Bias,
Backtest Overfitting, and Non-Normality*, Journal of Portfolio Management 40(5), 94-107
— https://www.davidhbailey.com/dhbpapers/deflated-sharpe.pdf

```
DSR = PSR(SR*)

SR* = sqrt(V[{SR_k}]) · [ (1-γ)·Φ⁻¹(1 - 1/N) + γ·Φ⁻¹(1 - 1/(N·e)) ]

PSR(SR*) = Φ( (SR^ - SR*)·sqrt(T-1) / sqrt(1 - γ₃·SR^ + ((γ₄-1)/4)·SR^²) )

  γ  ≈ 0.5772 (Euler-Mascheroni) · Φ = 표준정규 CDF
  γ₃ 왜도 · γ₄ 첨도 · T 관측 수 · N 시도 횟수 · V[{SR_k}] 시도 조합들의 Sharpe 분산
```

**검토자 답변 — 우리가 막혔던 두 질문**

| 질문 | 답변 |
|---|---|
| 시도 횟수 N을 뭘로 잡나 | **전체 파라미터 공간 크기(4×4=16)를 기본**으로 하고, 세션 내 사용자가 클릭해 새로 실행한 횟수를 **누적 가산**하는 것이 표준 관행 |
| 사이클 단위 손익에도 쓸 수 있나 | 가능. **T를 완료 사이클 수로 바꾸고**, 사이클 수익률의 왜도·첨도를 계산하면 논리적으로 동일 |
| 입력값 누락 | 없음 (SR^, V[{SR_k}], N, T, γ₃, γ₄) |

**프로젝트 판정: 수용 — 착수 대기**

1차 회신에서 이 두 답이 잘려 보류했으나, 전문 수령으로 **차단 요인이 해소**됐다.
`computeParamMap`이 이미 16조합을 전부 돌리므로 `V[{SR_k}]`는 부산물로 나온다.
남은 구현 과제는 Φ⁻¹(역정규 CDF) 근사 하나뿐이다.

**다만 화면 문구는 신중해야 한다.** DSR은 0~1 확률값으로 나와 "0.87이면 좋은 것"처럼
읽히기 쉽다. 이 도구의 목적은 사용자를 안심시키는 게 아니라 **최고값 사냥을 말리는 것**이므로,
"통과/탈락" 뉘앙스가 아니라 "16번 시도한 것을 감안하면 이 성과는 …" 형태로 서술한다.

## ③ PBO (Probability of Backtest Overfitting)

**검토자 판정**: 사실 · **난이도**: 브라우저 JS 가능(S=10 시 약 50ms) · **권고**: 선택(DSR 이후 2단계)

**출처**: Bailey, Borwein, López de Prado & Zhu (2017), *The Probability of Backtest Overfitting*,
Journal of Computational Finance 20(4), 39-69 — https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf

- CSCV가 원 논문의 핵심 방법론이 맞음
- 조합 수 = C(S, S/2). **S=16이면 12,870개**로 메인 스레드 지연 위험. **S=10이면 252개**로 급감
- 경량화: 파라미터 조합별 S개 블록 Sharpe **행렬을 선계산**하면 5,000캔들 기준 252회 매칭이 50ms 이내
- DSR과는 **보완 관계**. DSR은 단일 선택 전략의 Sharpe 왜곡 보정, PBO는 IS 최적 전략이 OOS에서 중앙값 이하로 열화될 **확률 자체**를 측정
- 하나만 넣는다면 O(1)로 가장 가벼운 **DSR**

**프로젝트 판정: 수용 — 후순위.** DSR 구현·검증 후 착수.

## ④ 몬테카를로 재표본

**검토자 판정**: 사실 · **권고**: 이 전략엔 **가격 경로 부트스트랩만 유효**(거래 결과 셔플은 부적합)

**출처**: Politis & White (2004), *Automatic Block-Length Selection for the Dependent Bootstrap*,
Econometric Reviews 23(1), 53-70 — https://public.econ.duke.edu/~ap172/Politis_White_2004.pdf

- 무한매수법은 하락 시 분할 매수하는 경로 의존 전략이라 **거래 손익만 셔플하면 전략 로직이 무력화**된다.
  기초자산 **가격 수익률 시계열을 블록 부트스트랩으로 재표본**한 뒤, 그 경로 위에서 전략을 다시 돌려야 한다
- 단순 셔플은 자기상관·변동성 군집을 파괴 — 의뢰서의 우려가 맞음
- 블록 길이: 일봉 T≈3,000~5,000 기준 **b ≈ T^(1/3), 약 15~20일**
- 백테스트를 B회 반복해야 하므로 **Web Worker 환경 구성 시 도입 권장**

**프로젝트 판정: 수용 — 구현 완료 (2026-08-06).**
인라인 Web Worker(Blob URL)로 해결했다. 엔진 함수를 `toString()`으로 직렬화해 주입하므로
별도 파일 없이 단일 HTML이 유지된다. B=500, 블록 b=round(T^⅓)(TQQQ 2,914일 → 14일),
시가는 전일종가 대비 비율로 같은 블록에 묶어 갭 구조 보존, 날짜열·세율은 원본 유지.
난수는 시드 고정(mulberry32)으로 재현 가능 — 검증 완료.
실측 TQQQ: 실측 +250.2%가 500개 대체 역사의 **53백분위**, 5% +66.3% / 95% +347.9%.

논쟁적 수식이 없어 잔여 회신 없이도 정직하게 세울 수 있는 유일한 지표였기 때문이다.

**단, 순위만으로는 거짓말이 된다** — 포트폴리오 실측에서 자체 발견한 함정이다.
미국 3자산에서 평균 검증순위가 1.8위/6으로 나와 "지속성 있음"으로 읽힐 뻔했으나,
실제 6종의 성과 격차는 평균 **1.4%p**였다. 사실상 동점인 구간에서 1위를 맞춘 것을
실력으로 포장하는 셈이다. 따라서 **구간 내 최고~최저 격차를 먼저 보고**,
격차가 5%p 미만이면 순위와 무관하게 *"주기 선택이 성과를 거의 바꾸지 않았다 — 순위는 잡음"*으로
판정하도록 게이트를 넣었다.

**남은 것**: WRC / Hansen SPA (둘 다 부트스트랩 반복 필요 — 몬테카를로 워커 위에 얹으면 됨)
